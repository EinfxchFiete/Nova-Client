Microsoft-Login
  1. Öffne das Azure-Portal → App-Registrierungen und erstelle eine neue Registrierung („Persönliche Microsoft-Konten“).
  2. Unter Authentifizierung: „Öffentliche Clientflows zulassen“ auf Ja stellen.
  3. Kopiere die Anwendungs-ID (Client-ID) hier oben hinein.
  4. Beantrage bei Mojang die Freischaltung für die Minecraft-API: aka.ms/mce-reviewappid. Erst danach funktioniert der Login.
